Block

Building the model

Floor tiles are walkable tunnel. The walls, rails and corners are added around them automatically.

Door tiles go in the rock right next to one floor tile. The doorway is two tiles wide, centred on the door tile, and the door tile is the warp.

Save the block file, then drag it onto build_underground_block.bat in the tools folder. It writes NAME_map_data.bin next to the block file: the finished block (collision plus model) ready to use as a map_data file. The .imd and .nsbmd model files are written too.
